Delivery

Delivery

We deliver and install pool tables islandwide. Our team handles the transportation and setup process carefully to help ensure your pool table reaches the installation location safely and is prepared for proper play.

Accessories Included

All necessary accessories are provided with the pool table, and there is no additional charge for these included accessories.

Islandwide Delivery

We provide delivery service to installation locations throughout Sri Lanka.

Delivery Charge

If the pool table is delivered to an installation location within Colombo, there is no delivery fee,
If it is out of Colombo, it will be charged based on the required transportation distance and arrangements as our stock is stored in Colombo.

How the delivery & installation process works
01

02

Arrange transportation from Colombo.

03

04

Complete the required installation and labour work.

Installation

Installation

Professional installation helps ensure the pool table is assembled correctly, positioned properly and prepared for smooth, consistent play. Our team carries out the installation with attention to alignment, stability and the condition of the playing surface.

Correct Assembly

We assemble the major components of the pool table carefully according to the table structure and required installation method.

Positioning & Levelling

The table is positioned and levelled as required so the playing surface is properly aligned for a better playing experience.

Precision Setup

We use appropriate tools and installation techniques to secure the table and make sure the components are correctly fitted.

Ready for Play

After installation, the table is checked so it is stable, properly arranged and ready for use.

Installation fee: An installation fee is charged separately based on the labour required to assemble, position, level and prepare the pool table for use.

Repair
